## Run it

```bash
python hello.py
```

## GitHub basics (the short version)

1. A **repository** is a project folder on GitHub.
2. A **commit** is a saved snapshot of your files.
3. A **branch** is a copy of the project where you try changes safely.
4. A **pull request (PR)** is a request to merge those changes into `main`.
5. An **issue** is a to-do, bug, or idea.
